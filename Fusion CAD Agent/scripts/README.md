# scripts/

Fusion Python scripts — generated by the local model, and hand-written ones worth keeping.

## Layout
- `_template/` — the known-good skeleton. Copy the whole folder and rename **both** files to match the folder name; Fusion requires `<Name>/<Name>.py` + `<Name>/<Name>.manifest`.
- One folder per script, named after the part.

## Getting a script into Fusion
Fusion only sees scripts under its own support folder:

```bash
open ~/Library/Application\ Support/Autodesk/Autodesk\ Fusion\ 360/API/Scripts/
```

Copy or symlink a script folder there, then in Fusion: **Utilities → Scripts and Add-Ins → Run**. New folders may need a Fusion restart, or add them with the green `+` in that dialog.

Symlinking from this folder keeps the source under git while still letting Fusion run it:

```bash
ln -s "$HOME/Claude/Fusion CAD Agent/scripts/MyPart" ~/Library/Application\ Support/Autodesk/Autodesk\ Fusion\ 360/API/Scripts/MyPart
```

⚠️ Symlink behaviour with Fusion's script loader is **untested** — if it misbehaves, copy instead.

## Conventions
- Every dimension is a named constant at the top of the file.
- Every script comments its unit conversions (the API is in **cm**, always).
- Every script states its assumptions in a header comment.
- Scripts that will run unattended must **not** call `ui.messageBox` — it blocks forever with no one to click it.
