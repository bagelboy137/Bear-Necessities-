# Part: Modular Overland Camp System — Base Frame

**Purpose:** the shared cube chassis every module is built on (cook, storage, fridge, sink, water, gear). Getting this one right defines all six.
**Project:** Bear Necessities (product) · CAD by Fusion CAD Agent
**Status:** draft

## Envelope
- Overall: **24"W × 20"D × 18"H** (outside dimensions)
- Material: **80/20 aluminium T-slot extrusion, 1010 series (1" × 1")**
- Process: cut extrusion + corner brackets, bolt-together

## Interfaces (must be exact)
| Feature | Dimension | Tolerance | Why |
|---|---|---|---|
| Outside width | 24.000" | ±0.030" | modules sit side by side in the vehicle |
| Outside depth | 20.000" | ±0.030" | must clear the tailgate |
| Outside height | 18.000" | ±0.030" | modules stack |
| Extrusion profile | 1.000" square | — | 1010 series |

## Structure
12 members forming a rectangular cube:
- 4 × horizontal width members
- 4 × horizontal depth members
- 4 × vertical corner posts

Cut lengths must account for the 1" profile so **outside** dimensions land at 24 × 20 × 18.

## Explicitly free
- Corner bracket style, fastener callouts, cosmetic detail.

## Deliverable
A 2D technical drawing: **three orthographic views (front, top, right) plus a cut list**, in DXF.
