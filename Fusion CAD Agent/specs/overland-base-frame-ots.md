# Part: Base Frame — OFF-THE-SHELF BUILD

**Purpose:** the shared cube chassis for all six modules, built entirely from catalog 80/20 parts so it can be drop-shipped from an extrusion supplier with zero custom fabrication.
**Status:** draft

## Envelope
- Overall: **24"W × 20"D × 18"H** OUTSIDE
- Material: **80/20 10 Series, part 1010-S** (1" × 1" smooth T-slot). TNUTZ EX-1010 is an equivalent.

## Construction — post and rail
12 members, all 1" × 1" square cross-section:
- **4 vertical corner posts**, 18.000" long, at the four corners, running the full height
- **4 width rails**, 22.000" long, running along X, fitting BETWEEN the posts
- **4 depth rails**, 18.000" long, running along Y, fitting BETWEEN the posts

Rails sit at the very top and very bottom of the frame. Everything unions into one connected solid measuring exactly 24 × 20 × 18.

## Why these lengths
Posts are the full 18" height. Rails fit between posts, so each is the outside
dimension minus two 1" profiles: width rail = 24 − 2 = 22", depth rail = 20 − 2 = 18".
**Posts and depth rails are both 18", so there are only TWO distinct cut lengths.**

## Interfaces (must be exact)
| Feature | Dimension | Tolerance |
|---|---|---|
| Outside width | 24.000" | ±0.030" |
| Outside depth | 20.000" | ±0.030" |
| Outside height | 18.000" | ±0.030" |
| Profile | 1.000" square | — |

## Deliverable
STEP + STL of the assembled frame.
