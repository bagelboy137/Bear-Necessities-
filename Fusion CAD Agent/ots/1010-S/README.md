# 1010-S frame rails

The frame's only two members: 80/20 `1010-S` (1 × 1 in, four open T-slots, smooth
surface) cut to the two lengths in `Bear Necessities/product/build-plans/01-frame-cut-list-and-bom.md`.

| File | What | Per frame |
|---|---|---|
| `BN-rail-1010S-18in.step` | 18 in rail: corner posts and depth rails | 8 |
| `BN-rail-1010S-22in.step` | 22 in rail: width rails | 4 |
| `build_rail.py` | Rebuilds both from the parameters below | - |
| `profile-iso.png` | 1 in stub of the profile, for reading its shape | - |

Both STEPs are in **real millimetres**: they open in Fusion at 1 × 1 × 18 in and
1 × 1 × 22 in, not 25.4× small. In an assembly they are two components and twelve
occurrences.

```bash
uv run --script "Fusion CAD Agent/ots/1010-S/build_rail.py"
```

The script uses build123d (it declares its own dependency), refuses to write
anything that misses 80/20's published section, and re-measures each file it
writes. `bncad selftest` checks the committed files on every `./build.sh test`.

## How faithful it is

| | Value | Source |
|---|---|---|
| Section | 1.000 × 1.000 in | 80/20, published |
| Centre bore | ø0.205 in through | 80/20 drawing callout |
| Slot opening | 0.256 in | 80/20 drawing callout |
| Slot depth, face to cavity floor | 0.323 in | 80/20 drawing callout `.323 TYP`. Reading it as the depth is an interpretation |
| Lip thickness | 0.087 in | **assumed**, typical 10-series |
| Cavity width under the lips | 0.584 in | **assumed**, typical 10-series |
| Cavity walls | 45°, parallel to the diagonal webs | **assumed** |
| Where the 45° wall starts | solved: 0.157 in deep | chosen so the area equals 80/20's figure |

**Checks against 80/20's published figures:**

| | Model | 80/20 |
|---|---|---|
| Cross-section area | 0.437 in² | 0.437 in² (fitted) |
| Ix = Iy | 0.0468 in⁴ | 0.0463 in⁴: **+1.1%, not fitted** |
| Mass, 18 in, aluminium at 2.70 g/cm³ | 348 g | 346 g (0.0424 lb/in) |

Good for assemblies, renders, mass and stiffness estimates. **Not good for**
checking how T-nuts, bolts or brackets fit inside the slot: the interior is
simplified. Use 80/20's own CAD for `1010-S` for that.

Sources: [8020.net 1010-S](https://8020.net/1010-s.html),
[1010-S profile drawing (Air Inc)](https://airinc.net/wp-content/uploads/2021/09/1010-S-Profile.pdf),
[FPE Automation listing](https://shop.fpeautomation.com/products/80/20%201010-S).
Built 2026-10-18 with build123d 0.13 through the `build123d` MCP server, then
regenerated by `build_rail.py`.
